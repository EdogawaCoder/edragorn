# Edragorn

Edragorn is a modular robotics architecture focused on developing intelligent autonomous assistant systems.

This project represents a long-term research and engineering initiative dedicated to exploring:

- Computer vision and perception systems
- Autonomous decision-making frameworks
- Human-robot interaction design
- Modular robotic system architecture
- Future mobility and manipulation integration

Current Stage

Phase 1 – Perception module (Windows + OpenCV)

The current development phase focuses on:

- Camera integration
- Visual processing pipelines
- Target tracking foundations
- System state architecture

Project Structure

edragorn/
├── edragorn_brain/
│   ├── win-perception/
│   └── ros2-core/
└── docs/

Roadmap (Early Phase)

- Implement real-time human tracking
- Define system state machine (searching / tracking / idle)
- Migrate perception logic to ROS2
- Introduce simulation environment

Edragorn（エドラゴン）は、知的な自律型アシスタントシステムの開発を目的としたモジュール型ロボティクスアーキテクチャです。

本プロジェクトは、以下の分野を中心とした長期的な研究およびエンジニアリング活動として設計されています。

- コンピュータビジョンおよび知覚システム
- 自律的意思決定フレームワーク
- ヒューマンロボットインタラクション設計
- モジュール型ロボットシステムアーキテクチャ
- 将来的な移動および軽量マニピュレーション統合

現在の開発段階は、視覚処理モジュールの基盤構築に焦点を当てています。

本リポジトリは、システムの技術的進化と設計思想を記録することを目的としています。
